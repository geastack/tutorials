# Node tutorials

Each folder is a separate tutorial. Numbered folders inside it are the
progressive steps for that tutorial.

1. [Build a native Hono todo API](./01-native-hono-todo-api/README.md) — start
   with Hello World, introduce types and modules, build a Hono API, then add
   MongoDB persistence.

## Before you start

The tutorials install `geatsc` in each project snapshot. This records the
compiler version in `package.json` and lets everyone working on the project use
the same version.

You may also install the compiler globally, like `tsc`:

```sh
npm install --global @geastack/compiler
```
